Cómo usar KEY IPTV

  1. Entra en Conexiones y elige el tipo de fuente.
  2. Para M3U, pega la URL o selecciona un archivo local.
  3. Para Xtream, introduce la URL base, el usuario y la contraseña entregados por tu proveedor.
  4. Guarda la conexión y pulsa Cargar. Luego selecciona un canal.
  5. Puedes agregar varias fuentes y cambiar entre ellas desde el selector en Ver TV.
Compatibilidad: las listas remotas necesitan conexión a internet. Si el servidor bloquea CORS, el navegador no podrá descargar la lista directamente. Prueba con el archivo M3U local o solicita al proveedor acceso compatible.

Privacidad: los perfiles se guardan en el almacenamiento local del navegador de este dispositivo. No uses un dispositivo compartido y elimina los perfiles cuando ya no los necesites. Los enlaces y credenciales son responsabilidad del usuario. Usa únicamente listas y servicios para los que tengas autorización.

Esta es una aplicación web. No incluye canales ni servicio IPTV, no evade bloqueos y no garantiza compatibilidad con todos los formatos o proveedores.
